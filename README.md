# Dawnlight Halls - Dice Calculator for Perfect World

This tool can help you to quickly see the available dice options in any dice state.
To use it, simply set the current dice faces as they are in the game and then select which dice spawned to manipulate the main dice.
Below the available options it will show you the sequence to kill the dies.
After clicking on the dice that you chose, the dice above will update to the new state and you can select the spawned dice again.
Repeat this as long as needed.
